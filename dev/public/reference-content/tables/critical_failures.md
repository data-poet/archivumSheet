<summary>Desarmado</summary>

|      3d6      | Descrição                                                                                                                                                                               |
| :-----------: | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|     **3**     | Você se nocauteia. Faça um teste de [[HT]] a cada 30 minutos para se recuperar.                                                                                                         |
|     **4**     | Você distende o membro usado no ataque: sofre 1 ponto de dano e o membro fica incapacitado por 30 minutos. Se atacou com mordida ou cabeçada, sofre dor moderada por (20 - HT) minutos. |
|     **5**     | Você acerta um objeto sólido em vez do alvo e sofre o seu próprio dano de [[GDP]] como contusão. Se atacou alguém com uma arma de empalamento preparada, você se empala nela.           |
|     **6**     | Como o **5**, mas com metade do dano. Uma arma natural (garras, dentes etc.) se quebra em vez disso: **-1** no dano até curar.                                                          |
|     **7**     | Você tropeça e para 1 metro depois do oponente, de costas para ele. Se estava aparando, você cai.                                                                                       |
|     **8**     | Você cai no chão.                                                                                                                                                                       |
| **9, 10, 11** | Você perde o equilíbrio (como o **7** da tabela de Armas).                                                                                                                              |
|    **12**     | Você tropeça. Faça um teste de [[DX]] para não cair (DX **-4** num chute, ou o dobro do redutor da técnica usada).                                                                      |
|    **13**     | Você baixa a guarda. Suas Defesas Ativas sofrem **-2**, e os efeitos de Avaliar ou Finta contra você dobram.                                                                            |
|    **14**     | Você tropeça (veja **7**).                                                                                                                                                              |
|    **15**     | Você distende um músculo: sofre **1d6-3** de dano, **-1** em tudo no próximo turno e **-3** em ações com o membro afetado até curar (**-1** com Hipoalgia).                             |
|    **16**     | Você acerta um objeto sólido (veja **5**).                                                                                                                                              |
|    **17**     | Como o **4**. Animais com IQ 3 a 5 fogem ou se rendem em vez disso.                                                                                                                     |
|    **18**     | Você se nocauteia (veja **3**).                                                                                                                                                         |

> [!NOTE]
> Quem não pode cair sofre **1d6-3** de dano em vez de cair. Quem voa ou nada fica numa posição desajeitada: **-4** para atacar e **-3** para se defender.
